# Security Policy & Disclaimer

---

## 1. Important Financial Disclaimer

> [!IMPORTANT]
> **STONKS is a research and decision-support platform.**
> * **NOT Financial Advice**: Nothing in this codebase, prediction report, or interactive shell constitutes professional financial, investment, legal, or tax advice.
> * **NO Automated Trading**: STONKS does not contain automated trade execution connectors or live brokerage transaction APIs. All positions are logged locally within mock session files.
> * **Historical Performance**: Past performance stats, backtesting cage allocations, or CAGR indicators do not guarantee future profitability. Use simulated parameters responsibly.

---

## 2. Supported Versions

Only the current main release candidate is actively supported with security patches:

| Version | Supported |
| :--- | :---: |
| v1.0.x (Release Candidate) | Yes |
| < v1.0.0 | No |

---

## 3. Responsible Disclosure

If you discover a security vulnerability or security bug, please report it responsibly:
* **Private Report**: Do NOT create a public GitHub Issue. Instead, email a private report detailing the vulnerability to the project owner at `krish@stonks-project.org` (placeholder).
* **Details to Include**: A clear description of the vulnerability, step-by-step instructions to reproduce the issue, and potential impacts.
* **Resolution Window**: We aim to acknowledge reports within 48 hours and provide a resolution within 14 days.
